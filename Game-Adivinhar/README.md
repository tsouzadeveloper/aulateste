## 🎲 Jogo de Adivinhação: Maior, Menor ou Igual
Um pequeno jogo de console desenvolvido em C onde o jogador tenta vencer o computador escolhendo um número e um tipo de comparação lógica.
## 📝 Como funciona?

   1. O computador gera um número aleatório entre 1 e 100.
   2. O jogador escolhe uma condição de vitória:
   * M (Maior): O jogador vence se o seu número for maior que o do computador.
      * N (Menor): O jogador vence se o seu número for menor que o do computador.
      * I (Igual): O jogador vence se o seu número for exatamente igual ao do computador.
   3. O programa compara os valores e exibe o resultado final.

## 🚀 Tecnologias Utilizadas

* Linguagem C
* Bibliotecas padrão: stdio.h, stdlib.h e time.h

## 🛠️ Como Executar
Para compilar e rodar o projeto, você precisará de um compilador de C (como o GCC).

   1. Clone ou baixe o arquivo do código.
   2. Abra o terminal e compile o programa:
   
   gcc jogo.c -o jogo
   
   3. Execute o programa:
   
   ./jogo
